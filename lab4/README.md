# SAT101 Lab 4 — archived

This directory is kept for historical reference. The lab has been renumbered
and rewritten as **ISA104 Lab 5, Track B**; the current student-facing
instructions live in [`../lab5/README.md`](../lab5/README.md).

The answer table, failing-case IDs and grading expectations that used to
appear in this file were **instructor-only material** and have been removed. **On
2026-11-21 the two companion servers `server_a.py` and `server_b.py` were also
removed from this public repository**: `server_b.py` carried answer-bearing
comments naming all five planted defects and their expected behaviour. They now
ship only in the instructor-only course pack and in the bundled student kit,
whose copies have every answer-bearing comment stripped. Track B asks you to
infer defects from the exported evaluation report alone, so no answer key is
distributed here. Instructors should use the answer key and rubric shipped with
the course pack.

For course context see the [root README](../README.md), especially
"Standards context (not a compliance claim)" and "Course linkage".

> The hosted demo at `https://mcp-eval.streamlit.app` is a demo only. Lab 5
> must be run locally with the bundled kit, because a cloud instance cannot
> reach `localhost:8101` / `localhost:8102` on your machine.
